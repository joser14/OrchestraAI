Ollama parallel slots

          

        
Compact cache
stores Ollama's working memory at 8-bit: about half the graphics memory per token, quality loss negligible. Keeps models fully on the GPU (faster) and leaves room for more context or a second worker. Restarts Ollama.

          

        
Context size
how much each agent can read at once. 24k suits most jobs; bigger is slower, and small models lose focus past ~32k. Applied now.

OpenClaw how each agent runs; saved straight into its OpenClaw job

      
Interpret requests
before main plans, one quick extra step rewrites your latest message as one clear instruction ("you missed one" → what exactly to fix). Adds about 5–15 s, only when there is a conversation to read.

        

      
Fast path for simple requests
a one-step ask (write, summarize, translate, convert…) goes straight to a free worker and the result comes back to you directly, without the composer's planning pass. Jobs with steps, research or comparisons still go through the composer.

        

      
Review before done
finished tasks wait in a Review column on the Tasks page for your Approve or Request changes; the composer reports only approved work

        

      
Learn from conversations
after the team answers you and is idle, keep lasting preferences, facts and what worked in memory/learned.md (Memory page); agents get the most relevant entries

        

      
Thinking
lets a model reason before it answers: better decisions, slower runs. Qwen3 models on Ollama only switch it on or off (low / medium / high act the same). They sometimes write a tool call inside their thinking instead of making it; Orchestra routes OpenClaw's model traffic through its own proxy, which turns those back into real calls (the Activity log says when it does) and measures the live speed for the Dashboard.

      

      
Light context
start runs with OpenClaw's lightweight bootstrap (fewer workspace files read in): faster first token, less background for the agent

        

      
Run time limit
OpenClaw stops a run after this long; Orchestra treats one still going 3 min later as stuck
